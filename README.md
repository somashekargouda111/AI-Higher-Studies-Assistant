# AI Higher Studies Assistant 🎓

An AI-powered Streamlit chatbot that helps undergraduate students explore postgraduate study pathways based on their academic background, interests, career goals, and study preferences.

> **AI provider:** This version uses Google Gemini through Google's OpenAI-compatible API endpoint. It does not use the OpenAI API itself.

## Features

- Conversational guidance for postgraduate study exploration
- Context-aware responses using recent chat history
- Student profile displayed in the sidebar
- Collection of academic background, interests, career goals, and study preferences
- Support for students from different academic backgrounds
- Quick-action prompts for common guidance tasks
- Friendly handling of common API errors

## Technology Stack

- Python
- Streamlit
- Google Gemini API
- OpenAI Python client (used as an OpenAI-compatible client)
- `python-dotenv`

## Run Locally

### 1. Clone the repository

Replace `YOUR_USERNAME` with your GitHub username:

```powershell
git clone https://github.com/YOUR_USERNAME/AI-Higher-Studies-Assistant.git
cd AI-Higher-Studies-Assistant
```

If you are working from your existing local folder, you can skip cloning.

### 2. Create and activate a virtual environment

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
pip install -r requirements.txt
```

### 4. Configure the API key

Create a `.env` file in the project root. Add your own key and the Gemini model that you have verified works with your account:

```text
GEMINI_API_KEY=your_google_ai_studio_api_key_here
GEMINI_MODEL=your_available_gemini_model
```

Do not commit `.env` or publish your API key. The `.env.example` file should contain placeholders only.

### 5. Start the application

```powershell
streamlit run app.py
```

Open the local URL shown in the terminal, usually `http://localhost:8501`.

## How It Works

1. A student describes their academic background, interests, or goals.
2. The application sends the conversation and known profile context to Gemini.
3. Gemini generates a relevant response and may provide structured profile information.
4. The application displays the response and updates the profile when profile data is returned.
5. The student can continue the conversation with additional preferences.

The exact wording of responses varies because they are generated by an AI model.

## Security

- Keep `.env` out of Git.
- Never place API keys in Python source files, screenshots, or README text.
- Use placeholder values in `.env.example`.
- If a key is accidentally committed or shared, revoke/rotate it.
- For a hosted deployment, configure the key using the hosting provider's secrets settings.

## Limitations

- AI responses can be inaccurate or incomplete.
- Profile extraction may occasionally misinterpret information; check the sidebar.
- The application does not automatically verify university fees, admission requirements, or deadlines against official university websites.
- Availability and rate limits depend on the Gemini model and account.
- Conversation/profile persistence depends on the current application implementation; do not assume long-term database storage unless it has been added.

Students should verify university requirements, fees, scholarships, and deadlines on official university websites.
